# 01. 아이트래킹 (IR → 시선 벡터)

> **원칙: 바닥부터 만들지 마라.** 동공 검출은 이미 잘 된 오픈소스가 있다.

## 소프트웨어 스택
- **pupil-detectors** + **pye3d** (pip 설치 가능)
  - 2D 동공 검출을 넘어 **3D 안구 모델**(안구 중심 + 시선 노멀)을 피팅.
  - 중요 이유: 안경 미끄러짐(slippage)·카메라 흔들림에도 3D 모델이 더 강건.
- 대안(나중에 필요 시 교체): RITnet / EllSeg 딥러닝 세그멘테이션.
  - **처음엔 pye3d로 시작**, 필요하면 교체.

```bash
pip install pupil-detectors pye3d
```

## 하드웨어 핵심
- **OV9281 (B0332)**: 모노크롬 글로벌 셔터 → IR에 적합.
- **IR 조명**: 850nm LED로 조명.
- **IR 밴드패스 필터**: LED 파장에 맞춰 렌즈 앞에 부착.
  - **없으면 실내 조명 변화에 동공 검출이 흔들린다.** 이 필터 유무가 검출 안정성을 좌우.
- **ROI 크롭**: 눈만 크게 잡히게 **400×400** 정도로 크롭 → 60fps 이상.

## 캘리브레이션 = 정확도의 90%
**방식: 2D→2D 직접 매핑** (강력 추천)
- 시선 벡터를 **"스테레오 카메라 이미지 픽셀"에 직접 매핑**.
- 절차:
  1. 장면에 마커 **9~13개** 배치.
  2. 각 마커를 차례로 응시.
  3. 다항식 회귀 또는 pye3d의 bundle-adjustment 매핑을 피팅.
- **이점**: 눈↔스테레오 카메라 사이의 정밀한 외부 파라미터(extrinsic)를 따로 구할 필요가 없어진다.
  → 이 시스템에서 제일 골치 아픈 부분을 우회하는 트릭.

## 임시 대체 (IR 카메라 미도착)
연구실 RealSense로 눈 카메라 자리를 대체해 파이프라인·캘리브레이션 절차를 먼저 검증.
