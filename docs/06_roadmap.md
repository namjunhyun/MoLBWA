# 06. 단계별 실행 계획 (리스크 낮추는 순서)

> 무선이랑 Pi를 처음부터 다 붙이면 뭐가 문제인지 못 찾는다. **변수를 하나씩 제거**하는 순서로.

## 0단계 — 전부 유선, 데스크톱 직결  ← **현재 여기**
- Pi도 무선도 없이, USB 연장선으로 카메라 다 데스크톱에 꽂는다.
- 목표: 각각 독립 확인
  - 아이트래킹이 안정적 시선을 주는가?
  - 스테레오가 깊이를 주는가?
  - SLAM이 도는가?
- **융합 수식을 책상 위에서 먼저 검증.**
- **IR 미도착 → RealSense로 눈 카메라 자리 대체 시험.**

## 1단계 — 오프라인 융합
- rosbag으로 **동기화된 데이터셋 녹화**.
- 캘리브레이션 제대로 잡기.
- 시선 → 월드 → 시각화 파이프라인을 오프라인에서 완성.
- **여기서 정확도를 뽑아낸다.**

## 2단계 — 센싱을 Pi로 + 무선
- Pi: 캡처 + 동공검출 + GStreamer 스트리밍.
- 데스크톱: SLAM + 융합 + 시각화.
- 대역폭 튜닝.

## 3단계 — 실시간 + 안경 장착
- 온헤드 마운트.
- 실시간 뷰어.
