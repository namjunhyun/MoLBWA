# 07. 정확도 기대치 (한계 지적이 아니라 설계 지침)

## 시선 정확도
- 잘 캘리브레이션된 **DIY 착용형 시선추적 ≈ 1~2°**.
- 2m 거리에서 **횡방향 3.5~7cm 오차**.

## 스테레오 깊이 오차
- **거리 제곱에 비례해서 커진다.**
- oCamS 베이스라인(~12cm) 기준으로 **몇 m까지는 신뢰**할 만함.
- 그 이상 멀어지면 깊이 정밀도가 **급격히 떨어진다.**

## 결론 → use case 설계
- 실내 **근~중거리**(책상, 물체, 사람 정도)에 강함.
- 데모/논문용 use case를 그 범위로 잡으면 결과가 깔끔하게 나온다.

## 사용자 강점 (프로젝트 적합성)
- ORB-SLAM3 스테레오-이너셜 경험 + ROS2 + 스트리밍 경험 → 거의 딱 맞음.
- 완전히 실현 가능. 융합 수식(03)과 IR 필터 동공검출(01)만 0~1단계에서 확인되면 나머지는 엔지니어링.
