# 데모 2 확장 — 지원이 대화 (CLOVA Studio VLM) 설계

2026-10-14 · 브랜치 `feat/g1-emotional-demo` · 상태: **초안, 사용자 검토 대기**

## 1. 목표와 범위

**목표**: 독거 어르신이 시선 추적 안경을 쓰고 방 안의 물건(가족사진·달력·꽃)을 바라보면, 휴머노이드 지원이가
그 물건 쪽을 같이 보고(가리키기) 돌아와 짧게 말을 걸고(정서 교감), 어르신의 대답에 1~3턴 이어서 대화한다.

**정해진 것 (2026-10-14 브레인스토밍)**
- 로봇팔 데모와 **별개 시연**. 휴머노이드는 정서 교감만, 물리적 개입 없음 (계획서 기준).
- 대상: **가족사진(회상 대화, 핵심)**, **달력(다가오는 기념일, 보조)**, 꽃·그림(가벼운 대화). **약은 제외.**
- 역할 분리: **YOLO 가 물체를 찾고 이름을 붙이고, VLM 은 그 결과를 컨텍스트로 받아 말만 만든다.**
- 동작: 같이 보기 = 물체 쪽 회전 → 가리키기(손바닥 위) → 착용자 쪽 회전 → 박수/손 흔들기 (`attend` 명령, 구현됨).
- 반응: **음성 + 시선** (지원이를 보면 계속, 다른 데 보면 마무리).
- 처리 위치: **클라우드 우선 + 로컬 대비** → 클라우드는 **NAVER CLOVA** (이 문서).
- 화법: **묻지 않고 건네기** ("기억나세요?" 금지 — 인지 저하 어르신에게 시험처럼 들림).

**범위 밖**: 로봇팔 연동, 약·복약 안내, 손글씨 달력 OCR(기념일은 등록 데이터로), 사람 얼굴 인식.

## 2. 사용할 CLOVA API (2026-10-14 문서 확인)

| 용도 | API | 핵심 |
|---|---|---|
| 대화 생성 (VLM) | CLOVA Studio Chat Completions v3, **HCX-005** | `POST https://clovastudio.stream.ntruss.com/v3/chat-completions/HCX-005`, `Authorization: Bearer <API 키>`, 이미지는 content 에 `{"type":"image_url","dataUri":{"data":"<base64>"}}` (턴당 1장, 긴 쪽 ≤2240px, ≤20MB), 스트리밍은 `Accept: text/event-stream`, `maxTokens`·`temperature` |
| 텍스트만 빠르게 | HCX-DASH-002 | 이미지 불필요한 후속 턴용(경량). 이미지 입력은 HCX-005 만 |
| 음성 → 글자 (STT) | CLOVA Speech Recognition (CSR) | `POST https://naveropenapi.apigw.ntruss.com/recog/v1/stt?lang=Kor`, 바이너리 오디오(WAV 등), **최대 60초**, 응답 `{"text": ...}` |
| 글자 → 음성 (TTS) | CLOVA Voice Premium | `POST https://naveropenapi.apigw.ntruss.com/tts-premium/v1/tts`, 화자·속도·감정 파라미터, mp3/wav |

- 키 2종: CLOVA Studio API 키(대화) + NCP 애플리케이션 Client ID/Secret(STT·TTS, 앱 설정에서 각 서비스 체크 안 하면 429).
- **확인 필요**: CSR 문서의 두 번째 인증 헤더 이름(문서에 같은 이름이 두 번 — 오기로 보임, 보통 `X-NCP-APIGW-API-KEY`),
  요금·호출 한도, 어르신 대상 TTS 화자(차분한 여성/남성 목소리) 선택.

## 3. 전체 흐름

```
[안경]  씬 카메라 프레임 + 응시점(px) ──┐
        안경 마이크 ──────────────────┐ │
                                     │ │
[데스크탑 B]                          │ ▼
  ① 물체 검출: YOLO-World(열린 어휘: "family photo frame","calendar","flower pot","painting")
     → 민감 클래스 제거(약·사람 얼굴 등은 목록에 넣지 않음)
  ② 응시 확정: 응시점이 박스 안에 3초 (기존 LabelDwell 재사용)
  ③ 방위 계산: 물체 방향(안경 기준) + 지원이 AprilTag 상대 위치 → 지원이 기준 물체 방위·착용자 방위
  ④ 즉시 동작: attend(물체 방위, 착용자 방위) → 지원이가 돌아 가리키는 동안(5~8초) ⑤를 병렬로
  ⑤ 말 만들기: 잘라낸 물체 이미지 + YOLO 이름 + 등록 기억 데이터 + 대화 기록 → HCX-005 → 1~2문장
  ⑥ TTS → 지원이 스피커(SDK PlayStream) — 지원이가 착용자 쪽으로 돌아와 박수할 때 맞춰 재생
  ⑦ 대답 듣기: 지원이 말이 끝나면 마이크 열기(말하는 중엔 닫음) → VAD 로 말 끝 감지 → CSR → 텍스트
  ⑧ 이어가기 판단: 착용자가 지원이를 보며 대답 → ⑤로 (최대 3턴) / 다른 데 5초 → 마무리 인사 + 손 흔들기
```

## 4. 구성 요소 (새 파일, `ros2` 없이 파이썬 단독 프로세스로 시작)

| 파일 | 책임 | 입력 → 출력 |
|---|---|---|
| `g1/dialog/clova.py` | CLOVA 3종 API 얇은 래퍼 (HCX-005 대화·스트리밍, CSR, TTS). 타임아웃·재시도 1회 | 이미지/텍스트/오디오 → 텍스트/오디오 |
| `g1/dialog/memory.json` | **가족 기억 데이터** (보호자가 등록): 사진별 인물·사연, 기념일(날짜·누구·무엇) | — |
| `g1/dialog/prompt.py` | 시스템 프롬프트 + 대상별 지시(사진=회상, 달력=기념일, 꽃=가벼운 대화) 조립 | 대상·기억·기록 → messages |
| `g1/dialog/objects.py` | YOLO-World 검출 + 응시 히트 + 크롭 | 프레임·응시점 → (클래스, 박스, 크롭) |
| `g1/dialog/session.py` | 대화 상태기계: 대기 → 같이 보기 → 말하기 → 듣기 → (이어가기·마무리) | 이벤트 → attend 명령·TTS·STT |
| `g1/dialog/fallback.py` | 클라우드 실패 시 대비: 대상별 미리 쓴 문장 + (가능하면) 로컬 소형 모델 | — |
| 패널(`g1_panel.py`) | "대화 시험" 칸: 물체 종류 고르기 + 텍스트로 대답 입력 (안경·마이크 없이 시험) | — |

## 5. 프롬프트 원칙 (환각·윤리 방지)

- 시스템: "당신은 독거 어르신의 말벗 로봇 '지원이'. **1~2문장, 존댓말, 따뜻하게.** 사실은 **[기억 데이터]에 있는 것만** 말하고,
  없으면 지어내지 말고 가볍게 감상만. **'기억나세요?'처럼 기억을 시험하는 질문 금지** — 기억을 건네고, 감정·바람을 묻는다.
  의료·약·돈·정치 이야기는 하지 않는다."
- 사진: 등록된 사연이 있으면 그 사연으로 ("지은이 돌잔치 사진이네요. 그때 딸기 케이크 드셨다면서요.") / 없으면 사진 분위기 감상.
- 달력: 오늘 날짜는 **컴퓨터 시계**, 기념일은 **등록 데이터** — 달력 글씨를 읽지 않는다.
- 응답 길이 `maxTokens` ≈ 120, `temperature` 0.5. 출력에서 금지어(약 이름 등) 걸리면 대비 문장으로 교체.

## 6. 지연 예산 (목표: 응시 확정 → 첫 말소리 ≤ 8초, 대답 끝 → 다음 말 ≤ 3초)

| 단계 | 예상 | 숨기는 법 |
|---|---|---|
| 응시 확정 → attend 시작 | <0.2 s | — |
| 회전+가리키기+돌아오기 | 5~8 s | 이 동안 HCX-005 호출(병렬) — 말은 돌아와 박수할 때 |
| HCX-005 (이미지 1장, 짧은 답) | 1~3 s (미측정) | 동작 중에 끝남 |
| TTS | 0.3~1 s (미측정) | 동작 중에 끝남 |
| 대답 STT (짧은 발화) | 0.5~1.5 s (미측정) | 지원이 끄덕임 대신 손 흔들기 짧게 |
| 후속 턴 HCX | 1~2 s | 첫 문장 스트리밍 즉시 TTS |

→ **1단계에서 실제 지연을 재고 표를 실측값으로 바꾼다.**

## 7. 실패 대비

- 클라우드 타임아웃(4초)·오류 → 대상별 미리 쓴 문장(사진: "사진 속 분들 표정이 참 좋네요." 등)으로 즉시 진행. 대화는 1턴으로 마무리.
- STT 실패·무음 → "제가 잘 못 들었어요" 1회 → 다시 실패면 마무리 인사.
- 소음 심함 → 패널의 **누르고 말하기** 버튼으로 전환.
- 키·요금: `.env`(리포 밖, 커밋 금지)에서 읽는다. 시연 전 호출 한도 확인.
- 로봇 쪽은 기존 안전장치 그대로 (attend 는 라이브러리에 동작이 있을 때만 수락, 비상정지·관문 통과 정책만 실기).

## 8. 시험

- 단위: `clova.py` 요청 본문 조립(이미지 base64·헤더) — 네트워크 없이 / `prompt.py` 금지어·기억 데이터 주입 / `session.py` 상태 전이(가짜 STT·가짜 시선).
- 통합 1단계(로봇·안경 없이): 사진 파일 + 가상 응시점 → HCX-005 실제 호출 → TTS 를 노트북 스피커로 → **지연·문장 품질 기록**.
- 통합 2단계: 시뮬 지원이(MuJoCo) + 패널 + 실제 CLOVA → 동작과 말 타이밍 맞추기.
- 통합 3단계: 실기(젯슨 스피커 PlayStream) + 안경.

## 9. 진행 순서 (예상)

1. **CLOVA 키 발급·호출 확인** (사용자) + `clova.py`·프롬프트 + 사진 1장으로 대화 품질·지연 측정 — 반나절
2. `objects.py`(YOLO-World 4클래스) + 응시 히트 + 크롭 — 반나절
3. `session.py` 상태기계 + 패널 "대화 시험" + 시뮬 연결 — 1일
4. 마이크(무선 핀마이크)·VAD·CSR + 번갈아 말하기 — 반나절
5. 젯슨 스피커 재생(PlayStream) + 실기 리허설 — 반나절

## 10. 열린 질문

- CLOVA Studio 키를 이미 발급받았는지(계정·과금 주체), 대회 기간 호출 한도.
- 가족 기억 데이터: 시연용 가상 가족(이름·사진·사연)을 우리가 만들지, 팀원 실제 사진을 쓸지.
- 로컬 대비 모델을 둘지(데스크탑 GPU 가 VLA 학습과 공유 중) vs 미리 쓴 문장만으로 대비할지.
