# 2026-09-23 시선 캘리브 재개 — 뷰어 버그 2개, F 키, 입력 모델 변경

## 뷰어가 죽던 원인 (`1b59a39` 회귀)
UDP 블록을 기존 if/else 사이에 끼우면서 else 가 엉뚱한 if 에 붙었다.
- `status` 미할당 → 시작 직후 동공이 잡히면 `UnboundLocalError` 로 exit 1.
  (인수인계 문서의 "원인 미확인 exit 1" 이 이것. 안 죽을 때는 옛 "NOT CALIBRATED" 문구가 남았다)
- `--source ros` 인데 `--send-udp` 가 없으면 눈 shim 을 로컬 USB 열기로 덮어써서 재연결 루프.

## F 키는 한 번도 동작한 적이 없었다
안구 모델 고정(F)은 `Orlosky3DEyeTracker` 자체 루프에만 있었고 `gaze_on_scene.py` 에는
연결돼 있지 않았다(모든 브랜치 확인). 고정하지 않으면 안구 중심(최근 200개 평균)이 매 프레임
갱신돼 캘리브 도중 시선 기준이 움직인다 — 인수인계 §5 "시선 벡터 재현성" 문제의 유력한 원인.
연결하고 씬 창에 `sphere=LOCKED/AUTO` 표시.

## affine 입력: (x/z, y/z) → (x, y)
눈 카메라가 눈을 비스듬히 봐서 z 가 0.48~0.94 로 흔들린다. 1차 10점:
원시 x ↔ u 상관 0.990 인데 x/z 로는 가로 잔차 31px. 같은 점에 (x,y) 로 47.6 → 36.8px.
2차항은 LOO 에서 과적합(24.7 → 33.3px)이라 기각 — 남은 오차는 비선형이 아니라 잡음.

## 결과 (`--flip`, 머리 고정, 안구 모델 고정)
| | 점 | 적합 | LOO |
|---|---|---|---|
| 1차 (고정 전·x/z) | 10 | 47.6px | — |
| 2차 | 11 | **17.7px** | 24.7px (0.6m 에서 약 3.2cm) |

컵 중심 간격 10cm 이상이면 구분에 충분.

## 운영 규칙
- 눈 영상은 `--flip`(180°). 옛 캘리브 파일은 뒤집기 전 기준이라 무효.
- **안경을 쓸 때마다 캘리브한다.** affine 은 그 세션의 안구 중심 기준이다.
  안경을 벗지 않고 뷰어만 재시작했으면 `--restore-eye-model`.
- 9점 이후 자동 저장은 마지막 점이 불량(중앙값의 2.5배)이면 건너뛴다. `u` = 마지막 점 취소.
  (2차 12번째 점, 깜빡임 142px 가 17.7px 결과를 55.8px 로 덮어쓴 일이 있었다)

## 환경 함정 추가
- Pi 눈 카메라 USB 가 재열거되면 `/dev/videoN` 이 바뀌고 v4l2_camera 가 멈춘다.
  `ssh a-hri@192.168.50.189 ~/eye_restart.sh` (by-id 로 찾아 눈 노드만 재시작).
- `pkill -f` 의 `[_]` 트릭은 **같은 명령 문자열에 원래 이름이 글자 그대로 있으면** 소용없다
  (예: kill 과 `nohup python3 gaze_on_scene.py` 를 한 명령에). kill 과 launch 를 분리할 것.
- 뷰어는 SIGTERM 에 안 죽는다(rclpy 스레드) — `kill -9` 또는 창에서 `q`.
